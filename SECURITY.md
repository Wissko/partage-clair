# Signaler un problème

N'envoyez aucun document personnel, original ou extrait confidentiel dans une issue.
Reproduisez le problème avec un fichier synthétique.

Pour une fuite de données ou une vulnérabilité, utilisez le signalement privé GitHub :
https://github.com/Wissko/partage-clair/security/advisories/new

Si le signalement privé n'est pas disponible, ouvrez une issue indiquant uniquement
qu'un canal privé est nécessaire, sans détail d'exploitation ni fichier sensible.

Seule la version de développement courante est maintenue. Aucun audit indépendant ni
engagement de délai de correction n'est annoncé. L'application ne doit pas servir à
ouvrir des fichiers suspects : elle ne fournit aucune isolation de sécurité.
