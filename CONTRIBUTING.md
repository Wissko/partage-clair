# Contribuer

Le projet démarre le 14 novembre 2026. Les contributions utiles sont les bienvenues :
reproductions avec fichiers synthétiques, accessibilité de l'interface, documentation
et tests sur plusieurs systèmes.

1. Ouvrez une issue décrivant un besoin ou un défaut, sans document personnel.
2. Installez `python -m pip install -e ".[dev]"` dans un environnement virtuel.
3. Ajoutez un test lorsque le traitement ou la confidentialité change.
4. Exécutez les commandes de vérification du README, puis proposez une pull request.

Les contributions sont distribuées sous la licence MIT du projet. Ne soumettez aucun
code appartenant à un employeur ou à un tiers sans autorisation. N'ajoutez ni suivi
d'usage ni appel réseau au traitement des documents.

## Priorités

- Revue indépendante du moteur d'export et corpus de documents synthétiques.
- Navigation entièrement au clavier, zoom et positionnement précis des masques.
- Export non bloquant et annulation.
- Installateurs signés après validation et collecte des avis des dépendances.
- Traduction anglaise de l'interface.
